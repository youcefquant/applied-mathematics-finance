
# Applied Mathematics in Quantitative Finance

Welcome to my dedicated space for breaking down rigorous mathematical formulas from quantitative finance textbooks and transforming them into functional Python scripts. 

As a **Quant Analyst in the making**, my goal with this repository is to bridge the gap between abstract academic theory and hands-on computational modeling using real-world market data.

## 🎯 Repository Objectives
* **Theory-to-Code Translation:** Extract mathematical models from standard finance literature and implement them using Python.
* **Deterministic & Stochastic Modeling:** Explore simple multi-asset market concepts up to advanced probability measures step-by-step.
* **Empirical Validation:** Test textbook equations against live financial data fetched directly from Yahoo Finance (`yfinance`).
* **Data Visualization:** Map the outcomes of asset growth, portfolios, and risk factors using `matplotlib`.

## 📂 Current Modules & Learning Journey
1. **The One-Period Market Model (`One-Period-Model/`)**
   * **Mathematical Focus:** Discrete-time wealth distribution, portfolio value linear equations ($V_0$ and $V_1$), and positivity constraints ($S > 0, A > 0$).
   * **Computational Application:** Built a joint portfolio combining a risky asset (`AAPL`) and a risk-free bond index (`^IRX`) to compute historical simple returns ($K_V$) and plotted the daily compounding growth timeline.
